#  Fake News Headline Generator

A fun beginner Python project that generates random and funny fake news headlines.  
This project uses the `random` module to combine different subjects, actions, and places to make humorous fake headlines.

##  How to Run
1. Make sure you have Python installed.
2. Open your terminal in the project folder.
3. Run:
   ```bash
   python fake_news_generator.py
